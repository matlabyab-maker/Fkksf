# Fkksf — Fast Keyboard برای اندروید

## ویژگی‌ها
- کیبورد واقعی Android IME با چیدمان فارسی و انگلیسی
- ردیف ابزار فشرده: Paste، Copy، Undo، Redo، چهار جهت‌نما و تغییر زبان
- صفحهٔ نمادها، فاصله، حذف و Enter
- گردش ساخت GitHub Actions در `.github/workflows/android.yml`
- خروجی APK در بخش Actions → اجرای موفق → Artifacts با نام `Fkksf-debug-apk`

## ساخت با GitHub Actions
پروژه را در ریشهٔ مخزن `Fkksf` قرار دهید و با MGit به شاخهٔ `master` یا `main` پوش کنید. Workflow کامیت واقعی را چاپ می‌کند، Gradle 8.7 را نصب می‌کند و بدون نیاز به `gradlew` یا `sdkmanager tools`، فایل APK را می‌سازد.

## فعال‌سازی روی اندروید
1. APK را نصب کنید.
2. برنامهٔ Fkksf را باز کنید.
3. «فعال‌کردن کیبورد» را بزنید و Fkksf را در تنظیمات فعال کنید.
4. «انتخاب Fkksf» را بزنید و آن را به‌عنوان کیبورد انتخاب کنید.

## یادداشت فنی
این نسخه یک پایهٔ عملی و قابل ساخت است. Undo/Redo در IMEها به محدودیت‌های برنامهٔ مقصد وابسته است؛ این پیاده‌سازی عملیات سادهٔ حذف/درج را پوشش می‌دهد و جایگزین تاریخچهٔ ویرایش داخلی همهٔ برنامه‌ها نیست.
